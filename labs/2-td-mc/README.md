# 实验 3：随机游走上的 TD(0) vs MC（共写模式）

## 铺垫卡

1. **位置**：MC → TD → n-step → GAE → PPO。理论课上已经弄清了 TD 目标什么时候合理（马尔可夫性质），也从数字推出了 MC 误差 = TD 误差之和（式 6.6）。这一站要把两种方法真正跑起来，对比一下。
2. **问题**：同样的数据，TD 和 MC 谁学得快、谁学得准？原因是什么？
3. **用处**：PPO 的 critic 用 TD 类目标训练，GAE 的 λ 在 TD 和 MC 之间折中。看 critic 的误差曲线、调 λ 和学习率时，判断依据就是这次实验看到的现象。
4. **学完能做什么**：能用一局手算的轨迹核对 RL 更新代码；能从误差曲线判断“降得快”和“最终准”分别受什么影响；能用偏差和方差两个数说清 λ 在权衡什么。
5. **怎么练**：你写三个函数，分别是 TD 目标、TD(0) 更新和 MC 更新，其余代码都由我写好。三道题都要先写预测再运行：题 A 用来自查，题 B 看误差曲线，题 C 量化偏差和方差。
