# MuZero 导读

Schrittwieser et al., *Mastering Atari, Go, Chess and Shogi by Planning with a Learned Model*，arXiv 1911.08265v2（2020）。原文：`refs/W-MuZero.pdf`，共 21 页。下文页码都是这份 PDF 的页码。

## 一句话

MuZero 在**学到的模型**上做树搜索规划，不需要知道游戏规则。它学的模型不还原画面，只预测规划需要的三样东西：奖励、价值、策略。

## 要解决什么问题（第 1–2 页）

- **基于规划的方法很强，但需要规则。** AlphaZero 在围棋、国际象棋、将棋上做树搜索，每一步都要调用规则模拟器：走这一步之后棋盘变成什么样、谁赢了。这就是阶段 1 里的 p(s′, r | s, a)，网格代码里的 `next_state` 加上 `REWARD`。
- **很多环境没有规则可用。** Atari、机器人、驾驶都是这样。这类问题过去主要用无模型方法（如 DQN 系列、R2D2），在视觉复杂的环境上，基于模型的方法一直表现不好。
- **以前学模型的思路是重建观测**，也就是预测下一帧画面。画面里大部分像素和决策无关，模型容量花在了没用的地方，误差还会在多步推演中累积。
- **MuZero 的思路**：模型只需要让规划结果正确，不需要还原环境。论文第 4 页的原话是，隐状态 s^k “has no semantics of environment state attached to it”，它唯一的用途是预测策略、价值和奖励。第 2 页把这类模型称为 value equivalent（价值等价）模型。

## 方法（第 3–4 页，图 1，式 1）

### 三个函数

| 函数 | 输入 → 输出 | 作用 |
| --- | --- | --- |
| 表示函数 h | 过去的观测 o₁…o_t → 根节点隐状态 s⁰ | 把画面或棋盘编码成隐状态 |
| 动态函数 g | (s^{k−1}, a^k) → (r^k, s^k) | 学到的“规则”：执行动作后得到的奖励和下一个隐状态。论文里是确定性的（第 4 页） |
| 预测函数 f | s^k → (p^k, v^k) | 策略先验和价值，同 AlphaZero 的策略/价值网络 |

### 图 1 的三栏

- **A：规划。** 从 s⁰ 出发，沿着候选动作反复调用 g 往下展开，每个节点用 f 给出 p 和 v，做蒙特卡洛树搜索（MCTS）。棋类每步搜索模拟 800 次，Atari 50 次（第 4 页）。
- **B：行动。** 搜索结束后，按根节点各动作的访问次数得到搜索策略 π_t，从中采样真实动作 a_{t+1}。环境返回观测和奖励 u_{t+1}，整条轨迹存入回放缓冲区。
- **C：训练。** 从缓冲区取一段真实轨迹，用 h 编码起点，再用 g 沿真实动作展开 K = 5 步（第 4 页）。每一步 k 有三个目标：
  - 策略 p^k → 搜索策略 π_{t+k}
  - 价值 v^k → 价值目标 z_{t+k}
  - 奖励 r^k → 真实奖励 u_{t+k}

### 价值目标（第 4 页）

  z_t = u_{t+1} + γ u_{t+2} + … + γ^{n−1} u_{t+n} + γ^n ν_{t+n}

前 n 步用真实奖励，第 n 步之后接上搜索给出的价值估计 ν。这叫 n 步自举。Atari 取 n = 10；棋类直接用到终局，相当于预测最终胜负（附录 G，第 15 页）。

### 总损失（式 1，第 4 页）

  l_t(θ) = Σ_{k=0}^{K} [ l^r(u_{t+k}, r^k_t) + l^v(z_{t+k}, v^k_t) + l^p(π_{t+k}, p^k_t) ] + c‖θ‖²

三个头一起训练，梯度沿 g 的展开反向传播，即通过时间的反向传播（BPTT）。

## 结果（第 4–6 页）

- **棋类**：不给规则，性能与 AlphaZero 持平。围棋略超过 AlphaZero，而且每个节点的计算量更少。
- **Atari 57 个游戏**：均值和中位数都创下新纪录，在 42 个游戏上超过之前的最强无模型方法 R2D2，在全部游戏上超过之前的基于模型方法 SimPLe。
- **MuZero Reanalyze**（附录 H）：用最新的网络对旧轨迹重新搜索，生成新的训练目标，从而提高样本效率。

## 和阶段 1 主干的对应

| MuZero | 阶段 1 |
| --- | --- |
| g：(s, a) → (r, s′) | `next_state(s, a)` + `REWARD`，只不过 g 是学出来的 |
| f 输出的 v^k | 价值表 v |
| f 输出的 p^k | 不经过搜索、直接给出的策略先验。`greedy(v)` 要先用模型往前看一步才能得到策略，所以对应的不是 f，而是下面的“搜索” |
| 树搜索：用 g 往下展开，用 r + γv 回传 | `q_pi(v, s, a) = r + γ v[s′]` 再取 max，只是展开了很多步 |
| 搜索策略 π 比 p 更好，再训练 p 去逼近 π | 策略改进（S1.4）：对当前价值做贪心，得到更好的策略 |
| 训练 v 去逼近 z | 策略评估。z 是 n 步回报加自举，阶段 2 的 S2.3 会讲 |
| 搜索 → 训练 → 再搜索 | 广义策略迭代：评估和改进交替进行（SB §4.6） |

## 和三个目标方向的联系（资料外，仅作提示）

- **端到端驾驶（B1）**：学一个只为决策服务的隐空间世界模型，而不是预测完整画面，这和你“预测会不会撞，比预测下一帧更有用”的直觉是同一件事。
- **具身智能（B5）**：阶段 4 的窗口会话读 DreamerV3，它也是在学到的隐空间模型里训练策略，可以和 MuZero 对照着看：一个在模型里搜索，一个在模型里做 actor-critic。
- **大模型后训练（B3）**：“先用搜索得到更好的策略，再让网络去模仿它”这个结构，在大模型里也有对应的做法，例如先采样多个回答、挑出好的，再用它们做训练。具体等阶段 5 学到相关内容时再讨论。

## 读完可以自查的问题

1. g 和 AlphaZero 用的规则模拟器相比，输入输出有什么不同？为什么 s^k 不需要“像”真实棋盘？
2. 为什么用搜索策略 π 而不是 p 作为策略目标？用阶段 1 的“策略改进”来解释。
3. z_t 里 n 取很大，或者 n 取 1，各有什么好处和坏处？（阶段 2 学完 S2.3 再回来答。）

2026-10-04 窗口会话：兴趣**高**。三道题：
