# 参考资料

把以下资料放进本目录，Claude 解释时会锚定并标注出处：

- Sutton & Barto《Reinforcement Learning: An Introduction》第 2 版 PDF（作者官网 incompleteideas.net 免费提供）
- David Silver UCL RL 课程 slides（davidsilver.uk/teaching）
- Berkeley CS285 slides（rail.eecs.berkeley.edu/deeprlcourse）
- 阶段论文和窗口会话论文，用到时再加入

建议文件名带上缩写，例如 `SB2.pdf`、`DS-L04.pdf`、`CS285-policy-gradients.pdf`，便于引用。
