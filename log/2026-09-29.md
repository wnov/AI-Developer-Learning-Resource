# 2026-09-29 会话 3：理论 W1-T2（S1.3 ★）

## 做了什么

1. **复查 S1.1**（新题：+1, 0 交替的持续奖励）
   - 首答写出 G_{t+1} = G_{t+2}，错把相位不同的两段回报当成相等，得出 1/(1−γ³)。
   - 指出错误后，自己得出 G_{t+2n} 与 G_t 序列相同、G_{t+1} = γG_t，解出 1/(1−γ²)。
   - 结论：提示后完成，这次提示只指出了错在哪一步。
2. **预测题**（沿用 W1-T1 检验 2 的状态 s）
   - (a) 答对：永远选 a₁，V* = 2。
   - (b) 把策略参数化为 p，列出 V(p) 求最优，思路好，但**第三次漏了 γ**，得出"最大值无穷大"。提醒用 r_max/(1−γ) 的上界做合理性检查后改对：p = 0，V* = 5。
3. **推出 Bellman 最优方程**
   - 算出 Q*(s,a₁) = 2、Q*(s,a₂) = 5，得到 V* = maxₐ Q*。
   - 学习者对"最优点在端点"的解释是"V 是 p 的单调函数"，这只是本题公式上的表现；已纠正为一般原因：加权平均不超过最大值。
   - 代入 Q* 方程：首次把 max 加在了左边，右边漏了 Σ_{s'}，学习者自己察觉到"这个式子好像还是有点问题"。指出代入方向后写对了 Q*(s,a) = Σ P [r + γ max_{a'} Q*(s',a')]，即 SB 式 (3.20)；v* 版本为式 (3.19)，备份图见 SB 图 3.4。
4. **记号问题**（学习者提问）："Q(s,a) 中的 a 似乎有两种含义：动作空间和特定动作"。已解答：a 始终是具体动作，动作空间是 𝒜(s)；区别在于自由变量和哑变量。学习者答对了检查题："a 是自由变量，a' 是哑变量"。

5. **线性与非线性**（诊断 Q2(b) 的遗留问题）
   - V = r_π + γP_πV 是否线性：答"是，因为不含 V 的高次项"。已补充：V 只被常数矩阵乘、再与常数向量相加。
   - 闭式解：首答 `r_pi / (1-γ*P_pi)`，把标量公式搬到矩阵上。指出矩阵不能相除、"1" 不能直接照搬之后，改为 V = (E−γP_π)⁻¹ r_π，正确。对照 DS 第 2 讲第 36 页，以及第 23 页（直接解的代价是 O(n³)）。
   - V* 为什么不能一步解出：学习者说"不懂，问题的点在哪里看不出来"。改用单状态例子 V* = max(1+γV*, 2)，γ = 0.9：学习者自己检验了两个分支（a₂ 分支 V*=2，不成立；a₁ 分支 V*=10，成立），总结为"V 的最大值与 V 本身有关"。已补充：max 选哪个动作决定了系数矩阵，而这个选择依赖于未知数 V*。对照 DS 第 2 讲第 48 页、SB 第 64 页。
   - 追问穷举代价：n 个状态、每个状态 k 个动作，共 kⁿ 种确定性策略。学习者答出总代价约 n³·kⁿ，"不可行"。这为下周的策略迭代和价值迭代做了铺垫。
6. **检验**（新题，独立作答）
   - 检验 1（两状态 V^π，γ=0.5）：方程写对，γ 位置全部正确，解出 V(A)=1.2、V(B)=0.4。**全对**。
   - 检验 2（Q* 一步备份，γ=0.8）：选 3.6，**正确**。写法上 `Q^*(s_1,)` 漏了 max_{a'}。
   - 学习者追问："不过我没搞懂为啥Q*还和动作有关"。没有直接解释，而是加了动作 a₂ 让学习者计算：Q*(s,a₂)=5，V*(s)=5；3.6 的含义选 A（先强制执行 a，之后按最优策略行动），正确。对照 SB 式 3.16/3.17 和例 3.7（高尔夫，"committing to a particular first action"）。
