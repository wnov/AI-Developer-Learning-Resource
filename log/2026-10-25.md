4. “我们要算MC的标签的方差……跟V有什么关系”：学习者说得对，MC 标签不查表；我的上一条消息把三组取值并列，容易让人以为 MC 也和 V 有关。

6. 写完检查点后，学习者问：“方差需要多次采样才能算，我怎么可能直接就估算出来”。我答：概率已知时，方差可以直接按定义 Σ p·(x − 平均)² 算出来（均匀硬币的 0/1 方差是 0.25，不用真的抛）；MC 参考答案为 1 的概率就是 v_π(C) = 0.5，TD 第一步走左右的概率各 1/2；程序里 20000 局的采样是拿来核对手算的。下次做题 C 时，先确认这一点再开始。
7. 学习者问“MC的方差哪有什么取值概率的问题？”：我区分了单独一局 G_0 的方差（题 C 问的，取值 1 和 0 的概率各是把对应轨迹的概率加起来，各为 0.5）和 n 局平均的方差（S2.1 的 0.25/n）。学习者未回复是哪一种。
8. 学习者指出“‘每步都随机时为什么 λ 接近 0 更稳’这个观点这一题没讨论过”。说得对：第 (4) 问引用了题里没有的设定。已改为只用题 C 自己的数：V 不准时谁受影响；V 准时谁更吵、为什么（MC 的结局取决于每一步，TD 只取决于第一步）；分别对应 λ 的哪一头。
9. “什么叫每一步都随机”：用表里第 1、3 局（第一步都到 D，结局一个 1 一个 0）说明 MC 参考答案取决于每一步的硬币，TD 只取决于第一步，后面的硬币被 V(D) 顶替。
10. “每一步都随机这不是大前提吗，存在每一步不随机的情况吗”：答这是程度问题；A→C 反例完全确定，MC 方差为 0，此时 MC 全面占优；随机性来自策略和环境；大模型后训练里环境转移确定、奖励常在结尾给一次，GRPO/RLOO 不用 critic（相当于 MC 一头），InstructGPT 的 PPO 用 critic + GAE；驾驶和机器人随机多、轨迹长，通常 λ≈0.95（方向例子为资料外）。单元 4 小题的“每一步都很随机”应说成“随机性大、轨迹长”。

我的判断：主要原因在题 C 的设计，而不在上下文长度。题 C 一开始就用“目标的偏差和方差”这类抽象说法，没有先用几局具体轨迹把“参考答案”是什么讲出来；之后又一条一条零碎地补提示，每条只修一处。题 C 已经按 4 局表格的形式重写（先算离 0.5 差多少，再看方差，最后接 λ）。
